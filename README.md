# LS Refrigerações — Site institucional

Landing page da **LS Refrigerações** (instalação, desinstalação, manutenção preventiva e corretiva, higienização e recarga de fluido refrigerante).

## Recursos
- Hero com vídeo de 15s em loop infinito com crossfade, efeito parallax e neve animada
- Animações de entrada no scroll, contadores, frase que acende palavra por palavra, linha de progresso nos passos
- Cards com tilt 3D e brilho que segue o cursor, botões magnéticos
- Carrossel infinito flutuando da direita para a esquerda (desacelera no hover e aceita arrastar)
- FAQ em acordeão e formulário de orçamento que abre o WhatsApp
- Layout responsivo e suporte a `prefers-reduced-motion`

## Rodando localmente
Site estático (HTML, CSS e JS puro). Basta abrir o `index.html` ou servir a pasta:

```bash
python -m http.server 8000
```

> Telefone, e-mail, endereço, CNPJ, redes sociais e depoimentos são genéricos (placeholder).
> Vídeo do hero: clipes do [Mixkit](https://mixkit.co/) (licença gratuita). Fotos: [Unsplash](https://unsplash.com/).
